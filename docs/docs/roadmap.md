# MModel Roadmap

## 阶段一

目标：以 Grafana 为宿主入口，快速交付 MModel 的首个调查闭环。

范围：

- MModel Core 的基础对象、关系、证据和查询能力
- 基础 Diagnosis API
- MModel 页面嵌入 Grafana
- 时间范围同步
- 登录复用
- 原始数据跳转

## 阶段二

目标：沉淀通用平台适配层，降低接入新平台的成本。

范围：

- MModel Platform Adapter Layer
- Deep Link 规范
- Context Sync 规范
- Embedded View 规范
- 宿主平台接入模板

## 阶段三

目标：形成独立产品形态，并支持多个宿主平台共存。

范围：

- 独立 Web 入口完善
- 多平台适配
- Agent 调查能力增强
- 调查报告与协同能力增强

## 后续补充

后续版本需要补充：

- 里程碑时间表
- 人员与角色分工
- 风险项
- 每阶段验收标准
