# MModel 路线图

## 阶段一：快速交付调查闭环

目标：以 Grafana 作为宿主入口，优先交付首个可用的 MModel 调查闭环。

范围：

- 基础对象、关系、证据和查询能力
- 基础 Diagnosis API
- 实体探索、拓扑、证据与调查时间线页面
- 结构化诊断结果、影响面和调查报告页面
- Grafana 登录复用、时间同步和原始数据跳转

## 阶段二：沉淀平台适配层

目标：形成通用的平台适配能力，降低接入新平台的成本。

范围：

- MModel Platform Adapter Layer
- Deep Link 规范
- Context Sync 规范
- Embedded View 规范
- 宿主平台接入模板

## 阶段三：形成独立产品形态

目标：形成稳定的独立产品能力，并支持多个宿主平台共存。

范围：

- 独立 Web 入口完善
- 多平台适配
- Agent 调查能力增强
- 调查报告与协同能力增强

## 路线图原则

- 当前路线图建议每个阶段都优先沉淀 MModel Core，而不是优先沉淀单平台定制逻辑。
- 若后续接入新平台，建议尽量避免倒逼修改核心对象模型和调查主流程。
- 对外能力当前建议优先以 REST / SDK / MCP 形式稳定输出。
