## Project knowledge

This repository contains a **Grafana plugin** — the UModel console shipped as a Grafana app (id `deepsite-umodel-app`, `type: app` + Go backend). You must Read @./.config/AGENTS/instructions.md before doing changes.

For architecture, build/deploy, key configuration files, and **how the frontend adapts to Grafana**, read [docs/development-guide.md](./docs/development-guide.md). Key facts to keep in mind:

- **All backend access goes through the Go backend reverse-proxy** (`pkg/plugin/resources.go`, `proxyTo`) to the UModel server (`jsonData.apiUrl`, optional `secureJsonData.apiKey` injected server-side). There are **no `plugin.json` `routes`** and **no native Prometheus/Loki/Tempo data source** — metric/log/trace are graph entities queried via `/api/v1/query`. REST prefix is `/api/v1/umodel/*` and the SPL dialect is `.umodel`; `query/execute` returns a `QueryExecuteResponse` envelope that `UModelApi.query()` flattens via `normalizeQueryResult`.
- **The 6 pages, two frontend styles:** UModel / Topology / Query / Imports / Settings / API Debugger. Form pages (`src/pages/ImportsPage`, `SettingsPage`) are rewritten natively on `@grafana/ui` + `useStyles2`; heavy pages are ported into `src/features/{umodel,entityTopo,query,apiDebug}` and **theme-bridged** via `src/design/ThemeBridge.tsx` — `UModelRoot` maps the ported `--om-*` tokens (incl. `--om-primary*` / `--om-cjk-font` / `--om-scrim`) to `GrafanaTheme2` and injects them on `document.body` for portaled overlays. `WorkspacePage` is the shared shell; i18n (`src/i18n`) derives locale from the Grafana user language.
- **Zero hardcoded colors** — everything derives from the theme (Grafana best-practices); only data-viz identity colors / shadows / dark-tooltip white text stay hardcoded (with a comment). WebGL/canvas that can't read CSS (cosmos.gl) gets its color injected from `useTheme2()` (e.g. `CosmosEngineConfig.backgroundColor`). Monaco is always `@grafana/ui` `CodeEditor` (never the CDN `@monaco-editor/react`). Use `Combobox`, not the deprecated `Select`.
- The root `eslint.config.mjs` relaxes newer react-hooks rules for `src/features/{umodel,entityTopo,query,apiDebug}/**/*.tsx` (ported code); `react-hooks/exhaustive-deps` is turned **off** for the pure vendored viz `umodel`/`entityTopo` (re-synced verbatim) but stays an **error** for `query`/`apiDebug` with per-line justified disables. See dev-guide §3.6.
- Do **not** edit `.config/**` or the plugin `id`/`type`. Changing `plugin.json` requires a Grafana restart. Build the backend on a host with Go ≥ 1.26 (the dev container ships Go 1.21.6).
